ระบบสนับสนุนการตัดสินใจทำนายความเสี่ยงพ้นสภาพนักศึกษา (DSS)
==============================================================

ลิงก์ (ใช้ได้เมื่อรัน server อยู่ที่เครื่องนี้)
--------------------------------------------
หน้าเว็บหลัก ............................ http://127.0.0.1:8000
คู่มือ API (Swagger, ทดลองยิง API ได้) .... http://127.0.0.1:8000/docs
ดาวน์โหลดไฟล์ Excel ตัวอย่าง (Template) .. http://127.0.0.1:8000/api/v1/import-template
ดาวน์โหลดรายงาน Excel ................... http://127.0.0.1:8000/api/v1/export-excel
รายชื่อนักศึกษา (JSON) .................. http://127.0.0.1:8000/api/v1/students
สมัคร/สร้าง API key ของ Claude ........... https://console.anthropic.com

หมายเหตุ: เปิดด้วย 127.0.0.1 เท่านั้น ถ้าเปิดด้วย localhost หน้าเว็บจะโหลดรายชื่อนักศึกษาไม่ได้ (CORS)

API ที่หน้าเว็บใช้
-----------------
POST   /api/v1/predict-student          ทำนายความเสี่ยงและบันทึก
POST   /api/v1/extract-transcript       ให้ AI อ่านภาพ/PDF ใบผลการเรียน
POST   /api/v1/import-excel             นำเข้าไฟล์ Excel หลายคน
GET    /api/v1/students                 รายชื่อนักศึกษาทั้งหมด
GET    /api/v1/export-excel             ดาวน์โหลดรายงาน Excel
GET    /api/v1/import-template          ดาวน์โหลดไฟล์ตัวอย่าง
DELETE /api/v1/delete-student/{รหัส}    ลบนักศึกษา 1 คน
DELETE /api/v1/delete-all-students      ลบข้อมูลทั้งหมด

วิธีรัน server
--------------
1) ติดตั้งแพ็กเกจ (ครั้งแรกครั้งเดียว)
   pip install -r requirements.txt
2) รัน
   python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
3) เปิด http://127.0.0.1:8000

เปิดใช้ปุ่ม "ให้ AI อ่านเอกสาร"
------------------------------
1) สร้าง API key ที่ https://console.anthropic.com
2) ตั้งค่าในเครื่อง (อย่าใส่ key ไว้ในโค้ด)
   setx ANTHROPIC_API_KEY "sk-ant-..."
3) ปิดหน้าต่าง terminal แล้วเปิดใหม่ จากนั้นรัน server ใหม่

ข้อควรทราบ: ภาพเอกสารจะถูกส่งไปให้ Claude (Anthropic) อ่าน และมีค่าใช้จ่ายตามการใช้งาน
ผลที่ AI อ่านได้ต้องตรวจกับเอกสารจริงก่อนกดบันทึกทุกครั้ง

ข้อมูลที่กรอกในฟอร์ม
--------------------
- รหัสนักศึกษา, ชื่อ, นามสกุล
- ชั้นปี (ปี 1 - 4)
- หน่วยกิตที่สะสมได้ / หน่วยกิตตามแผนการเรียน
- ผลการเรียนรายภาค 1 - 8 ภาค: GPAX สะสม, จำนวนวิชา F/W, คะแนนเก็บ (%)
  (คะแนนเก็บบังคับเฉพาะภาคล่าสุด, ระบบนับภาคที่ติดวิทยาทัณฑ์ให้อัตโนมัติ)

เกณฑ์ข้อบังคับที่ระบบใช้ (แก้ได้ที่ต้นไฟล์ app/api/predictions.py)
------------------------------------------------------------------
- GPAX ต่ำกว่า 1.50 (หลังเรียนครบ 2 ภาค) = เข้าเกณฑ์พ้นสภาพ
- GPAX 1.50 - 1.99 = วิทยาทัณฑ์
- GPAX ต่ำกว่า 2.00 ติดต่อกันเกิน 2 ภาค = เข้าเกณฑ์พ้นสภาพ
- ปี 4 แต่ GPAX ต่ำกว่า 2.00 = ยังจบการศึกษาไม่ได้
- ระดับความเสี่ยงจาก AI: 51% ขึ้นไป = สูง, 41 - 50% = ปานกลาง, 40% ลงไป = ปกติ
ควรตรวจสอบเกณฑ์กับข้อบังคับของมหาวิทยาลัยกาฬสินธุ์ก่อนใช้งานจริง
