วิธีนำระบบ DSS ขึ้นเว็บ ให้ทุกคนเปิดได้ผ่านลิงก์ (ฟรี, ไม่จำกัดเวลา)
=====================================================================

ผลลัพธ์: ได้ลิงก์ประมาณ https://dss-dropout-risk.onrender.com
ใครมีลิงก์ก็เปิดใช้ได้จากทุกที่ ทั้งคอมและมือถือ โดยไม่ต้องเปิดเครื่องนี้ไว้

โปรเจกต์เตรียมไว้ให้แล้ว:
- render.yaml  = ตั้งค่าให้ Render สร้างเว็บ + ฐานข้อมูล PostgreSQL ให้อัตโนมัติ
- .env         = รหัสผ่านฐานข้อมูลในเครื่องนี้ (ไม่ถูกอัปโหลด)
- .gitignore   = กันไม่ให้ .env และไฟล์ขยะถูกอัปโหลด


ขั้นที่ 1: อัปโหลดโปรเจกต์ขึ้น GitHub (ทำครั้งเดียว)
--------------------------------------------------
1. สมัครบัญชีที่ https://github.com
2. ติดตั้ง GitHub Desktop: https://desktop.github.com แล้ว Sign in
3. GitHub Desktop > File > Add local repository > เลือกโฟลเดอร์ D:\1
   (ถ้าขึ้นว่ายังไม่เป็น repository ให้กด "create a repository" แล้วกด Create)
4. ตรวจรายการไฟล์ด้านซ้าย ต้องไม่มีไฟล์ .env
5. กด Commit to main > กด Publish repository
   แนะนำให้ติ๊ก "Keep this code private" ไว้

ขั้นที่ 2: สร้างเว็บบน Render
-----------------------------
1. สมัครที่ https://render.com (เลือก Sign in with GitHub จะง่ายที่สุด)
2. กด New + > Blueprint
3. เลือก repository ที่อัปโหลดเมื่อขั้นที่ 1 (ถ้าไม่เห็น ให้กด Configure GitHub แล้วอนุญาต repo นั้น)
4. Render จะอ่าน render.yaml แล้วแสดงรายการที่จะสร้าง: dss-dropout-risk (เว็บ) และ dss-db (ฐานข้อมูล)
5. ช่อง ANTHROPIC_API_KEY: ใส่ key ถ้าต้องการใช้ปุ่ม "ให้ AI อ่านเอกสาร" (เว้นว่างได้)
6. กด Apply แล้วรอ 5 - 10 นาที จนสถานะเป็น Live
7. ลิงก์ของระบบอยู่มุมบนของหน้า service dss-dropout-risk  <-- ส่งลิงก์นี้ให้คนอื่นได้เลย

ขั้นที่ 3: อัปเดตระบบในอนาคต
-----------------------------
แก้โค้ดในเครื่อง > GitHub Desktop กด Commit แล้ว Push origin
Render จะอัปเดตเว็บให้อัตโนมัติภายในไม่กี่นาที


ข้อควรรู้ (สำคัญ)
-----------------
1. ไม่มีระบบ login: ทุกคนที่มีลิงก์ดู แก้ และ "ลบข้อมูลทั้งหมด" ได้
   ห้ามใส่ข้อมูลนักศึกษาจริงจนกว่าจะเพิ่มหน้า login หรือรหัสผ่านสำหรับปุ่มลบ
2. ฐานข้อมูลบน cloud เริ่มต้นว่างเปล่า ข้อมูลในเครื่องนี้ไม่ได้ย้ายขึ้นไปด้วย
   (นำเข้าใหม่ได้ด้วยปุ่มอัปโหลด Excel บนเว็บ)
3. แผนฟรีของ Render (ตามเงื่อนไข ณ ตอนเขียน ควรตรวจที่ https://render.com/pricing อีกครั้ง):
   - ถ้าไม่มีคนเข้าเว็บประมาณ 15 นาที เว็บจะ "หลับ" คนแรกที่เปิดต้องรอประมาณ 1 นาที
   - ฐานข้อมูลแบบฟรีมีอายุจำกัด (ประมาณ 30 วัน) ถ้าจะใช้จริงระยะยาวต้องอัปเกรดฐานข้อมูลเป็นแบบเสียเงิน
     หรือ Export Excel เก็บไว้เป็นระยะ
4. ใบผลการเรียนที่ให้ AI อ่านจะถูกส่งไปที่ Anthropic และมีค่าใช้จ่ายตามการใช้งาน API key
